# 本机批准、调用和数据责任

在 **活动记录 → 批准与策略变更** 查看本工作区的批准和共享连接目录变更。编号随记录增长。服务会话 UUID 每次打开数据库后重新生成，不能用于登录。当前产品只有本机操作身份，无法用该编号辨认具体自然人。

连接、模型、成员、额度池和预算的变更与各自的审计记录在同一 SQLite 事务提交。策略快照保存连接标识、协议、API 源站、模型配置标识、并发上限、岗位允许的动作和配置摘要。自由文本、私有目录、系统提示及凭据引用仅参与摘要。摘要用来比较同一配置。批准时冻结相关预算、选中岗位、计划修订与路由摘要；浏览器继续使用旧批准时，路由或预算变化会要求重新确认。变更后的限额不会覆盖历史快照。

展开一次批准可查看规划或执行编号、调用预留状态与收到的结果。一次调度可关联多项执行。调用结果与计费单据各有自己的含义。已发出但未获得完整结果的调用应以供应方账单核对。进程中断时，历史执行结果可能显示未知。新的治理记录从第 10 次数据库迁移开始；此前的数据沿用工作区事件和已有预算台账。

**下载脱敏审计摘要** 按工作区生成另外一份 JSON，仅保留计数、序号、枚举状态、时长和已知 token 数。可识别的路由、会话编号和策略历史仅供通过本机会话读取。完整 SQLite 备份包含本机私有信息。[备份和恢复](operations.md)

同一批次的后续调用在预算预留和实际派发前均重新核对该调用适用的预算。如果较早的批准之后增加、删除或放宽了限额，旧批准无法继续按新限额派发。任务、计划的标识及其调用和 token 上限随批准冻结。工作区已完成的执行用于在重启后核对可能中断的审计写入。
